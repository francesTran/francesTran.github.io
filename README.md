# Frances Tran — portfolio

Plain HTML, no build step. Pages: `index.html` (About), `resume.html`, `experience.html`,
`projects.html`, `organizations.html`, `fun.html` (Music / Fitness / Learning / Travel), `contact.html`.
Images and the resume PDF are in `assets/`.

## Preview
Double-click `index.html`. Edit any page in a text editor, save, refresh.

## Add your photos
Drop photo files into `assets/photos/` using the names listed in `assets/photos/README.txt`
(main, burrito, hardware, travel, running, yogurt, copenhagen; .jpg/.jpeg/.png/.webp).
Refresh the page and they appear. No code editing needed.

## Deploy with GitHub Pages
1. Push everything in this folder (including `assets/` and `.nojekyll`) to the root of a repo.
2. Settings → Pages → Deploy from a branch → `main`, `/ (root)` → Save.
3. Live at `https://<username>.github.io/<repo>/` (or name the repo `<username>.github.io`).
File names are case-sensitive on GitHub Pages; keep image names as they are.
